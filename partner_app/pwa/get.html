夥伴看盤

自動當沖 · 只看自己的元大持倉與成交

安卓手機 / 平板

⬇ 下載 App
  1. 按上面下載 App,下載完點開檔案
  2. 手機問「安裝未知應用程式」→ 允許
  3. 出現「安裝增強防護」→ 右上 ⋮ → 開始深度掃描 → 安裝
  4. 打開「夥伴看盤」→ 輸入或掃描金鑰
以後有新版,打開 App 會自己問要不要更新。

蘋果 iPhone / iPad

打開夥伴看盤
  1. 用 Safari 打開這一頁(LINE 裡的話先點右下角「用瀏覽器開啟」)
  2. 按上面打開夥伴看盤
  3. 按下方中間的分享鍵(方框加箭頭)
  4. 往下滑,選加入主畫面 → 右上新增
  5. 從主畫面的「夥伴看盤」圖示打開 → 輸入或掃描金鑰
蘋果不能裝安卓的 App,用「加入主畫面」就跟 App 一樣全螢幕,每次打開都是最新版。iPhone 網頁版沒有震動,畫面關掉時不會響。

電腦(Windows / Mac)

打開夥伴看盤
  1. 用 Chrome 或 Edge 打開這一頁
  2. 有綠色安裝到電腦就按它;沒有的話按打開夥伴看盤,再按網址列右邊的安裝圖示(螢幕加箭頭)→ 安裝
  3. 桌面和開始功能表會出現「夥伴看盤」圖示,以後點它打開(獨立視窗)
  4. 輸入金鑰,或從相簿選 QR Code 圖片(電腦有鏡頭也可以按掃描)
電腦版不用下載 APK,每次打開都是最新版。視窗開著才會響(電腦沒有震動);第一次進去要按一下畫面,聲音才會開。
