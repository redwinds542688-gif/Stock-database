# 燈號單一條件測試(2026-10-21)

使用者:「撤掉 重新找其他方法」「所有改都要以最小的修改達到最大的效果 且不影響其他股票」。
在 App 頁面裡把 `ind3Lamps` 換成可掛條件的版本(`ind3Lamps_hook.js`,只在「剛要亮做多 / 做空」時檢查),跑 14 檔 × 10/19、10/20 兩天(28 股票日)。
- `lamp_search.py`:亮燈後 30 根內先順向 0.5% 算對;`lamp_search1.py`:60 根內 1%。條件清單 `cfgs.json`。

結果(60 根 1%):現行 71 對 59 錯 54%;10 根動能 < 0.3% 降級 56%、< 0.5% 57%、日內位置 < 0.1 57%、量比 < 0.7 56%、要在 Ap 對的一邊 55%、Oa 在 Ob 對的一邊 53%。
每個條件都會改到 20~27 / 28 個股票日,提升 2~3 個百分點,在 28 個股票日的樣本裡分不出是真的還是運氣。30 根 0.5% 的標準下現行 48%,所有條件都沒有比較好。
