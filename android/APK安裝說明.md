# 名揚四海 背景監控 App 安裝說明

## 安裝
1. 手機下載 `MyshMonitor.apk`,點開。
2. 手機會說「不明來源」或「不允許安裝此來源的應用程式」→ 點「設定」→ 允許 Chrome(或檔案管理)安裝 → 回來再點安裝。
3. 第一次打開 App:
   - 會問「允許通知」→ **允許**(不允許就收不到訊號)。
   - 右下角「☰」→「關閉電池最佳化(必做)」→ 選「允許」。沒做的話手機鎖屏一段時間後會把監控殺掉。
   - 三星 / 小米 / OPPO / vivo 另外要到「設定 → 應用程式 → 名揚四海自動交易 → 電池」,選「不受限制」或「允許背景活動」。

## 怎麼用
- **全自動**:裝好後打開一次(Android 規定沒打開過的 App 不會自動啟動),之後就不用再開。每個交易日 08:50 自動啟動監控、每 15 分鐘看門狗檢查、手機重開機也會自己起來。只有你自己按「☰ → 停止背景監控」才會停。
- 打開 App 就是原本的程式畫面,操作一樣。
- App 打開時會自動啟動背景監控,通知列會固定顯示「名揚四海 背景監控」。這個通知不能滑掉,滑掉就等於停止。
- 之後把 App 關掉、切到元大、鎖屏都沒關係,監控在背景繼續。
- 有新的「進場」「停利」「停損」「超6%」「出」就會跳通知 + 響鈴 + 震動(v1.5 起聲音走鬧鐘音軌,手機靜音、勿擾也會響;賠錢的用鬧鐘聲 + 長震動 8 秒),內容像:
  `群創 3481 做空進場 49.40` / `10:24 空✓ · 停利 47.42 停損 50.14`
- 監控的是程式清單上的股票(監控檔數 33 / 20 / 5),不是全部 100 檔。
- 週一~五 08:55~13:32 才監控,其他時間服務醒著但不做事。

## 右下角「☰」選單
| 項目 | 說明 |
|---|---|
| 啟動 / 停止背景監控 | 手動開關 |
| 監控狀態 | 看服務有沒有在跑、最後一次抓資料的結果 |
| 關閉電池最佳化(必做) | 第一次一定要按 |
| 更新程式(從 GitHub) | 規則改了以後,按這個就會把 GitHub 上最新的 `app/app.html` 抓下來,不用重裝 APK |
| 測試通知 | 看看通知會不會響 |
| 重新載入畫面 | 畫面怪怪的時候用 |

## 更新規則的流程(之後)
1. 我改好 HTML,放到 GitHub 的 `app/app.html`(合併到 main)。
2. 你在 App 按「☰ → 更新程式」。
3. 完成。不用重新安裝 APK。

## 注意
- 第一次啟動監控,會先把清單上每一檔的歷史分K抓下來(33 檔約 30~60 秒),之後每 5 秒問一次證交所即時價。
- 手機要有網路。4G 一天的流量大約幾十 MB。
- 如果通知列的「名揚四海 背景監控」不見了,代表被系統殺掉了,打開 App 會自動再啟動;請確認電池最佳化有關掉。
